# Source inputs

Place an entry-point COBOL program here and identify it in your assistant session.
Include available COPY members, called programs, SQL schemas, compiler/dialect
information, character encoding, sample data, and expected outputs.

Each conversion targets one selected entry program plus its required dependencies.
Multiple files in this directory do not imply that all of them should be converted.
Keep original sources unchanged. Source fixes or translated messages belong in the
session's decisions and generated application, not in the original files.

`SalaryReport.CBL` is an unconverted sample supplied by the user.
